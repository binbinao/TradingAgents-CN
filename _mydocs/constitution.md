## 🎯 项目愿景与使命

### 愿景
成为中文社区领先的AI驱动多智能体股票分析学习和研究平台，推动AI金融技术在中文社区的普及与正确应用。

### 使命
- **技术传播**: 让优秀的TradingAgents技术在中国得到更广泛的应用
- **教育普及**: 为中国的AI金融教育提供更好的工具和资源  
- **合规友好**: 提供合规的股票研究与策略实验平台，专注学习与研究用途
- **创新推动**: 推动中国金融科技领域的AI技术创新和应用

### 核心定位
面向中文用户的**多智能体与大模型股票分析学习平台**。帮助用户系统化学习如何使用多智能体交易框架与AI大模型进行合规的股票研究与策略实验，不提供实盘交易指令，平台定位为学习与研究用途。

## 🏗️ 技术架构

### 技术栈
- **后端**: FastAPI + Uvicorn（从Streamlit升级）
- **前端**: Vue 3 + Vite + Element Plus（从Streamlit重构）
- **数据库**: MongoDB + Redis 双数据库架构
- **AI框架**: 多LLM提供商支持（OpenAI、Google AI、国产LLM等）
- **部署**: Docker多架构支持（amd64 + arm64）

### 架构特点
- **企业级性能**: RESTful API + WebSocket + SSE多通道通信
- **多智能体系统**: 基于LangGraph的智能分析框架
- **数据源统一**: 支持Tushare、AkShare、BaoStock等
- **跨市场支持**: A股、港股、美股全覆盖

## 🤖 核心功能

### 智能分析功能
- **多智能体协作**: 市场分析师、基本面分析师、风险分析师等
- **动态模型选择**: 根据任务自动匹配最佳LLM模型
- **新闻智能分析**: 多层次新闻过滤与质量评估
- **技术指标计算**: 完整的技术分析指标体系

### 企业级功能
- **用户权限管理**: 完整的认证、角色管理、操作日志
- **配置管理中心**: 可视化大模型配置、数据源管理
- **缓存管理系统**: 智能多级缓存策略
- **实时通知系统**: 分析进度和状态实时推送
- **批量分析**: 多只股票同时分析
- **自选股管理**: 个人股票收藏与跟踪

### 数据与报告
- **多格式报告导出**: Markdown/Word/PDF专业报告
- **模拟交易系统**: 虚拟交易环境验证策略
- **股票智能筛选**: 多维度指标筛选排序
- **历史分析记录**: 完整的分析历史追踪
